<h2 id="problem">Problem</h2>
<div class="subtitle">Different material semantics need different filtering rules.</div>

A single linear average is rarely enough for every texture channel. Normal maps, roughness, opacity and tint masks each preserve different information.

<Callout label="Rule">
Treat mip generation as semantic processing, then pack channels per mip after each semantic chain has been built.
</Callout>

<h2 id="policy">Policy</h2>
<div class="subtitle">Make the filter choice explicit.</div>

```cpp
MipPolicy ResolvePolicy(TextureSemantic semantic)
{
    switch (semantic) {
        case TextureSemantic::Normal:    return MipPolicy::NormalAware;
        case TextureSemantic::Roughness: return MipPolicy::VarianceAware;
        case TextureSemantic::Opacity:   return MipPolicy::CoveragePreserve;
        default:                         return MipPolicy::Linear;
    }
}
```
